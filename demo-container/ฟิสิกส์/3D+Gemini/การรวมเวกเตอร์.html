การคำนวณสรุปขั้นตอน (Mathematical Steps)
1. ผลรวมแกน X ($\sum R_x$):
Rx = Ax + Bx = 4.00 + (-2.00) = 2.00
2. ผลรวมแกน Y ($\sum R_y$):
Ry = Ay + By = 3.00 + 3.46 = 6.46
3. ผลรวมแกน Z ($\sum R_z$):
Rz = Az + Bz = 2.50 + 0.00 = 2.50
4. ขนาดเวกเตอร์ลัพธ์ ($|\vec{R}|$):
|R| = √(Rx² + Ry²) = √(2.00² + 6.46²) = 6.76

เวกเตอร์คืออะไร? (General Concept of Vectors)

ปริมาณในทางฟิสิกส์แบ่งออกเป็น สเกลาร์ (Scalar) ที่มีเฉพาะขนาด และ เวกเตอร์ (Vector) ซึ่งมีทั้ง ขนาด (Magnitude) และ ทิศทาง (Direction) เช่น แรง ($\vec{F}$), ความเร็ว ($\vec{v}$), การขจัด ($\vec{d}$), และสนามไฟฟ้า ($\vec{E}$)

การแยกองค์ประกอบย่อย (Vector Components)

เวกเตอร์ใดๆ สามารถแตกเข้าสู่แกนอ้างอิงฉาก ($x, y, z$) ได้โดยใช้อัตราส่วนตรีโกณมิติ:
- แกนราบ ($x$): $A_x = |A| \cos\theta$
- แกนตั้ง ($y$): $A_y = |A| \sin\theta$
