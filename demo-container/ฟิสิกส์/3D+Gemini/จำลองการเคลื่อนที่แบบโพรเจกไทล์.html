ทฤษฎีโพรเจกไทล์ และประโยชน์ของ Simulation

ทำไมการใช้ Simulation ถึงดีสำหรับการศึกษาเรื่องนี้?

  • แยกองค์ประกอบของแรงได้ชัดเจน: ในโลกจริง เรามองไม่เห็นเวกเตอร์ความเร็ว Simulation ช่วยวาดลูกศร $v_x, v_y$ ให้เห็นว่าความเร็วแนวราบคงที่ (หากไม่มีแรงต้าน) แต่แนวดิ่งเปลี่ยนไปตามแรงโน้มถ่วง
  • ทดสอบเงื่อนไขที่ยากในห้องเรียน: การศึกษาผลของ แรงต้านอากาศ (Drag Force) หรือเปลี่ยน ความสูงเริ่มต้น ทำได้ยากและมีข้อจำกัดด้านพื้นที่ในห้องเรียน แต่ในคอมพิวเตอร์ทำได้ใน 1 คลิก
  • ทำนายผลและพิสูจน์ทันที: นักเรียนสามารถคาดเดาว่าถ้ายิงมุม 45° กับ 60° แบบไหนไกลกว่ากัน แล้วกด "ยิง" เพื่อยืนยันสมมติฐานได้ทันที ทำให้เกิดการเรียนรู้แบบ Active Learning
  • กราฟเส้นทาง (Parabolic Curve): แสดงรอยทางเดินของวัตถุค้างไว้ ทำให้เปรียบเทียบการทดลองหลายๆ ครั้งได้ง่าย คล้ายกับการใช้กระดาษคาร์บอนแต่สะดวกกว่ามาก

แนวราบ (แกน X)

ไม่มีแรงมากระทำ (หากปิดแรงต้านอากาศ) ทำให้ความเร็วคงที่ ($v_x = u_x$)

$$u_x = u \cos(\theta)$$ $$S_x = u_x t$$

แนวดิ่ง (แกน Y)

มีความเร่งจากแรงโน้มถ่วง ($g$) ในทิศลง

$$u_y = u \sin(\theta)$$ $$v_y = u_y - gt$$ $$S_y = h_0 + (u_y t - \frac{1}{2}gt^2)$$

การทำนายผลกระทบจากเงื่อนไขเริ่มต้น

1. มวล (Mass): ตามกฎของกาลิเลโอ หากไม่มีแรงต้านอากาศ มวลจะไม่มีผลต่อเส้นทางการบิน แต่ถ้ามีแรงต้านอากาศ วัตถุที่เบากว่าจะถูกหน่วงให้ตกเร็วกว่าวัตถุที่หนัก (ระยะทางสั้นลง) เนื่องจากความเร่งต้าน $a = \frac{F_{drag}}{m}$ จะมีค่ามากหาก $m$ น้อย

2. มุมยิง (Angle): มุม 45° จะให้ระยะทางไกลสุด (Range) บนพื้นราบ แต่ถ้าความสูงเริ่มต้น ($h_0 > 0$) มุมที่ตกไกลสุดจะน้อยกว่า 45° เล็กน้อย
