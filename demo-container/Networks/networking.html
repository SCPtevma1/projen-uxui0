1. โครงสร้างพื้นฐานและอุปกรณ์เน็ตเวิร์ก

องค์ประกอบกายภาพและอุปกรณ์เชื่อมต่อที่ส่งต่อข้อมูลทั่วโลกในเสี้ยววินาที

  • Router: ค้นหาเส้นทางที่ดีที่สุด (Routing) เพื่อส่งข้อมูลข้ามเครือข่าย เช่น เชื่อมบ้านเราเข้าสู่อินเทอร์เน็ต
  • Switch: กระจายสัญญาณและเชื่อมต่ออุปกรณ์ภายในเครือข่ายท้องถิ่น (LAN) ผ่านสาย LAN / MAC Address
  • Access Point & Wi-Fi: ส่งต่อข้อมูลผ่านคลื่นวิทยุความถี่ 2.4 GHz, 5 GHz และ 6 GHz (Wi-Fi 6/7)

2. ที่อยู่ดิจิทัล: IP Address & DNS

รหัสประจำตัวของอุปกรณ์ในโลกไซเบอร์และการแปลงชื่อเว็บเป็นตัวเลข

  • IPv4 vs IPv6: จากระบบ 32-bit (เช่น 192.168.1.1) สู่ 128-bit รองรับอุปกรณ์ IoT มหาศาล
  • Public vs Private IP: ไอพีจริงที่มองเห็นจากทั่วโลก vs ไอพีภายในบ้านผ่านระบบ NAT
  • DNS (Domain Name System): สมุดโทรศัพท์อินเทอร์เน็ต แปลงชื่อเว็บ เช่น google.com ให้เป็น IP Address

3. โปรโตคอลหลัก: TCP vs UDP

วิธีการขนส่งข้อมูลที่มีจุดเด่นและความเร็วแตกต่างกันตามประเภทการใช้งาน

  • TCP (Transmission Control Protocol): แม่นยำและตรวจสอบความสมบูรณ์ เหมาะสำหรับเว็บเพจ (HTTP/HTTPS), อีเมล, และดาวน์โหลดไฟล์
  • UDP (User Datagram Protocol): รวดเร็วแบบเรียลไทม์ ไม่รอตรวจเช็กแพ็กเก็ต เหมาะสำหรับวิดีโอคอล สตรีมมิง และเกมออนไลน์
  • HTTP/HTTPS: โปรโตคอลหน้าเว็บ โดย HTTPS มีการเข้ารหัสข้อมูลด้วย SSL/TLS อย่างปลอดภัย

4. ความปลอดภัยเครือข่าย (Cybersecurity)

การปกป้องข้อมูลและการป้องกันการโจมตีทางไซเบอร์ในยุคที่ทุกอย่างออนไลน์

  • Firewall: ปราการด่านแรกคอยกรองทราฟฟิกที่ไม่พึงประสงค์เข้าหรือออกจากเครือข่าย
  • VPN (Virtual Private Network): การสร้างอุโมงค์เข้ารหัสข้อมูลเพื่อความปลอดภัยบน Wi-Fi สาธารณะ
  • Zero Trust Architecture: แนวคิดความปลอดภัยยุคใหม่ "ไม่ไว้ใจใคร ต้องตรวจสอบเสมอ"
