รวมรายวิชา

เลือกวิชาที่สนใจเพื่อดูรายละเอียด

  • เขียนโค้ด ฝึกคิดเป็นขั้นตอนและสร้างโปรแกรม ดูรายละเอียด →
  • การเงิน เรียนรู้การออมและวางแผนรายรับรายจ่าย ดูรายละเอียด →
  • การตลาด รู้จักลูกค้าและการสื่อสารสินค้า ดูรายละเอียด →
  • ฟิสิกส์ เข้าใจแรง การเคลื่อนที่ และพลังงาน ดูรายละเอียด →
  • อวกาศ สำรวจดวงดาวและระบบสุริยะ ดูรายละเอียด →
  • อาหาร รู้จักโภชนาการและการเตรียมอาหาร ดูรายละเอียด →
  • ภาษาต่างประเทศ ฝึกภาษาเพื่อสื่อสารในชีวิตประจำวัน ดูรายละเอียด →
  • เคมี เรียนรู้สารและการเปลี่ยนแปลงรอบตัว ดูรายละเอียด →
  • การท่องเที่ยว วางแผนเดินทางอย่างสนุกและรับผิดชอบ ดูรายละเอียด →
  • การทำงานพื้นฐาน ฝึกวางแผน สื่อสาร และทำงานร่วมกัน ดูรายละเอียด →
  • พื้นฐานการต่อวงจร เข้าใจการทำงานของวงจรไฟฟ้า IOT อุปกรณ์ต่างๆ ดูรายละเอียด →
  • Networking เรียนรู้เกี่ยวกับเครือข่ายคอมพิวเตอร์และเทคโนโลยีการเชื่อมต่อ ดูรายละเอียด →
